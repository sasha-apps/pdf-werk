Wasserzeichen einfügen

Einen Text wie „ENTWURF“ oder „Nur zur Vorlage bei …“ über alle Seiten legen, etwa für Ausweiskopien.

    Deine Dateien werden nicht hochgeladen. Alles passiert direkt in deinem Browser.

    So fügst du ein Wasserzeichen ein

    1. Wähle das PDF aus.
    2. Gib den Text ein, z. B. KOPIE, ENTWURF oder Nur für die Wohnungsbewerbung.
    3. Klicke auf Wasserzeichen einfügen und lade das Ergebnis herunter.

    Häufige Fragen

    Wofür ist das gut?

    Wer eine Ausweis- oder Gehaltskopie verschickt, kann mit einem Wasserzeichen festhalten, wofür sie gedacht ist. Das erschwert den Missbrauch.

    Werden meine Dokumente hochgeladen?

    Nein. Gerade bei Ausweiskopien ist das wichtig: Alles passiert in deinem Browser.

    Selbst prüfen: Es wird wirklich nichts hochgeladen

    Öffne ein Werkzeug, schalte danach das WLAN aus oder dein Handy in den Flugmodus und benutze es. Es funktioniert trotzdem, weil die Bearbeitung auf deinem Gerät läuft. Ein Dienst, der deine Datei auf einen Server lädt, würde ohne Internet scheitern.
