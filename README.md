## Warum?

Viele PDF-Seiten laden deine Dateien auf einen Server. Bei Bewerbungen, Verträgen, Rechnungen oder Ausweiskopien ist das unangenehm. PDF-Werk bearbeitet alles auf deinem Gerät:

- **Kein Upload.** Prüfbar: Seite öffnen, Flugmodus an, Werkzeug benutzen. Es funktioniert trotzdem.
- **Keine Anmeldung, keine Grenzen, kein Wasserzeichen.**
- **Offline-Modus und als App installierbar** (Handy-Startbildschirm, PC).
- **Bequem:** Dateien überall ablegen oder mit Strg+V einfügen, Ergebnis direkt im nächsten Werkzeug weiterbearbeiten.

## Technik

Statische Website ohne Server-Code. Die Bearbeitung übernehmen [pdf-lib](https://pdf-lib.js.org/) (MIT) und [pdf.js](https://mozilla.github.io/pdf.js/) von Mozilla (Apache 2.0), beide werden mitgeliefert, es gibt keine Skripte von fremden Servern.

Dieser Branch enthält die gebaute Website, so wie GitHub Pages sie ausliefert.
