Seitenzahlen einfügen

Ein PDF durchnummerieren, zum Beispiel für Hausarbeiten, Bewerbungen oder Berichtshefte.

    Deine Dateien werden nicht hochgeladen. Alles passiert direkt in deinem Browser.

    So nummerierst du ein PDF

    1. Wähle das PDF aus.
    2. Wähle Position und Format der Seitenzahlen.
    3. Klicke auf Seitenzahlen einfügen und lade das Ergebnis herunter.

    Häufige Fragen

    Funktioniert das auch bei quer liegenden Seiten?

    Ja, die Seitenzahl steht immer unten auf der Seite, so wie du sie siehst.

    Wird das PDF hochgeladen?

    Nein, die Seitenzahlen werden in deinem Browser eingefügt.

    Selbst prüfen: Es wird wirklich nichts hochgeladen

    Öffne ein Werkzeug, schalte danach das WLAN aus oder dein Handy in den Flugmodus und benutze es. Es funktioniert trotzdem, weil die Bearbeitung auf deinem Gerät läuft. Ein Dienst, der deine Datei auf einen Server lädt, würde ohne Internet scheitern.
