Seiten aus PDF löschen

Leere, doppelte oder überflüssige Seiten aus einem PDF entfernen.

    Deine Dateien werden nicht hochgeladen. Alles passiert direkt in deinem Browser.

    So löschst du Seiten aus einem PDF

    1. Wähle das PDF aus.
    2. Gib die Seitennummern ein, die weg sollen, z. B. 1, 4-5.
    3. Klicke auf Seiten löschen und lade das neue PDF herunter.

    Häufige Fragen

    Wird meine Originaldatei verändert?

    Nein. Du bekommst eine neue Datei, das Original auf deinem Gerät bleibt, wie es ist.

    Werden die Dateien hochgeladen?

    Nein, alles läuft in deinem Browser.

    Selbst prüfen: Es wird wirklich nichts hochgeladen

    Öffne ein Werkzeug, schalte danach das WLAN aus oder dein Handy in den Flugmodus und benutze es. Es funktioniert trotzdem, weil die Bearbeitung auf deinem Gerät läuft. Ein Dienst, der deine Datei auf einen Server lädt, würde ohne Internet scheitern.
