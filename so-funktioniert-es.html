So funktioniert PDF-Werk

PDF-Werk bearbeitet deine Dateien auf deinem eigenen Gerät. Hier steht genau, wie das geht und was das für dich bedeutet.

Was passiert mit meiner Datei?

Wenn du eine Datei auswählst, liest dein Browser sie in den Arbeitsspeicher deines Geräts. Das Werkzeug ist ein JavaScript-Programm, das schon mit der Seite geladen wurde; es bearbeitet die Datei dort und stellt das Ergebnis als Download bereit. Die Datei wird an keinen Server geschickt, weder an unseren noch an einen anderen. Sobald du den Tab schließt, ist sie aus dem Speicher verschwunden.

Wie kann ich das prüfen?

  • Flugmodus-Test: Öffne ein Werkzeug, schalte das Internet aus und benutze es. Es funktioniert weiter. Ein Dienst, der hochlädt, würde scheitern.
  • Für Technikinteressierte: Öffne in Chrome oder Firefox die Entwicklertools (F12) und dort den Reiter Netzwerk. Während du eine Datei bearbeitest, erscheint dort keine Anfrage, die deine Datei überträgt.

Welche Technik steckt dahinter?

  • pdf-lib (MIT-Lizenz) zum Zusammenfügen, Teilen, Drehen, Nummerieren, Unterschreiben und für Wasserzeichen. Es verändert die Seiten nicht, sondern kopiert sie, deshalb bleiben Text und Qualität erhalten.
  • pdf.js von Mozilla (Apache-2.0-Lizenz), dieselbe Technik, mit der Firefox PDFs anzeigt. Sie zeichnet Seiten als Bild, für Vorschau, PDF in JPG und Verkleinern.

Beide Bibliotheken liegen auf unserem eigenen Webspace. Es werden keine Skripte von fremden Servern geladen.

Offline-Modus

Auf Wunsch speichert dein Browser die Programmdateien von PDF-Werk (nicht deine Dokumente), damit alle Werkzeuge auch ohne Internet starten, etwa im Zug. Du kannst das jederzeit wieder ausschalten.

Als App installieren

PDF-Werk lässt sich wie eine App auf den Startbildschirm legen:

  • iPhone und iPad (Safari): Teilen-Symbol antippen, dann Zum Home-Bildschirm.
  • Android (Chrome): Menü mit den drei Punkten, dann App installieren oder Zum Startbildschirm hinzufügen.
  • Windows und Mac (Chrome, Edge): In der Adresszeile auf das Installieren-Symbol klicken.

Grenzen

  • Passwortgeschützte PDFs lassen sich nicht bearbeiten.
  • Sehr große Dateien brauchen viel Arbeitsspeicher. Auf älteren Handys kann es bei PDFs mit Hunderten Seiten langsam werden.
  • PDF verkleinern wandelt Seiten in Bilder um; Text ist danach nicht mehr markierbar.
