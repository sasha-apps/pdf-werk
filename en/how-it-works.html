How PDF-Werk works

PDF-Werk edits your files on your own device. Here is exactly how, and what that means for you.

What happens to my file?

When you choose a file, your browser reads it into your device's memory. The tool is a JavaScript program that was loaded with the page; it edits the file there and offers the result as a download. The file is not sent to any server, neither ours nor anyone else's. When you close the tab, it is gone from memory.

How can I check that?

  • Airplane mode test: open a tool, switch off the internet and use it. It keeps working. A service that uploads would fail.
  • For the technically curious: open the developer tools (F12) in Chrome or Firefox and go to the Network tab. While you edit a file, no request appears that transfers it.

What technology is behind it?

  • pdf-lib (MIT license) for merging, splitting, rotating, numbering, signing and watermarks. It copies pages instead of redrawing them, so text and quality stay intact.
  • pdf.js by Mozilla (Apache 2.0 license), the same engine Firefox uses to show PDFs. It draws pages as images for previews, PDF to JPG and compression.

Both libraries are hosted on our own web space.

Offline mode

If you want, your browser stores PDF-Werk's program files (not your documents) so all tools start without internet, e.g. on a train. You can turn it off at any time.

Install as an app

  • iPhone and iPad (Safari): tap the share icon, then Add to Home Screen.
  • Android (Chrome): three-dot menu, then Install app or Add to Home screen.
  • Windows and Mac (Chrome, Edge): click the install icon in the address bar.

Limits

  • Password-protected PDFs can't be edited.
  • Very large files need a lot of memory. On older phones, PDFs with hundreds of pages can get slow.
  • Compress PDF turns pages into images; text can't be selected afterwards.
