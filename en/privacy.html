Privacy policy

Last updated: 25. Oktober 2026. The German version is authoritative.

1. Controller

Alexander Kasinski, Germany, email: sasha-apps@web.de. This website is a private, non-commercial service without advertising.

2. Your files

The PDF tools on this website run entirely in your browser. Files you choose are not transferred to our or any other server and are not stored.

This website sets no cookies. It only stores something in your browser when you explicitly use a feature (§ 25(2) no. 2 TDDDG):

  • "Remember settings on this device": if you tick this box, the options you chose for the tool (e.g. the compression level) are kept in your browser's local storage. Unticking the box deletes them.
  • "Continue with this PDF" and dropping a file on the home page: the file is briefly placed in your browser's storage (IndexedDB) so the next tool can open it, and deleted from there right away.

This data stays on your device and is not sent to us.

If you turn on offline mode on the How it works page, your browser stores this website's program files (HTML, CSS, JavaScript) on your device. This only happens at your explicit request (§ 25(2) no. 2 TDDDG) and contains no personal data. You can turn offline mode off there at any time; the stored files are then deleted.

3. Hosting and server log files

When you visit, the provider processes technically necessary data (IP address, time, page requested, browser) to deliver the site and protect it from attacks. The legal basis is our legitimate interest in a secure and working website (Art. 6(1)(f) GDPR). Data may be transferred to the USA; GitHub is certified under the EU-US Data Privacy Framework. More: GitHub privacy statement.

4. Advertising and analytics

This website includes no advertising, no analytics services and no content from third-party servers.
